# Riffusion Linter

A tool to help you create better vocal prompts for Riffusion AI music generation. The Riffusion Linter analyzes your prompts for potential issues and provides suggestions for improvement.

## Features

- **Syntax Checking**: Identifies syntax errors, unbalanced tags, and other formatting issues
- **Vocal Dynamics Visualization**: Visualizes the intensity and flow of your vocal performance
- **Pre-built Templates**: Provides ready-to-use templates for different vocal styles
- **Detailed Analysis**: Get insights about your vocal instructions with statistics and improvement suggestions

## How to Use

1. Clone or download this repository
2. Open `index.html` in a modern web browser
3. Enter your Riffusion prompt or load a template
4. Click "Analyze Prompt" to see detailed feedback
5. Revise your prompt based on the suggestions
6. Save your own templates for future use

## Templates Included

- Metal Screams & Growls
- Ethereal Whispers
- Pop Dynamic Range
- Emotional Ballad
- Rap Flow Variation
