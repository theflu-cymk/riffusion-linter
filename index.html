Riffusion Linter Help

Getting Started

The Riffusion Linter helps you create better vocal prompts for Riffusion AI music generation. Paste your lyrics with style instructions in the editor, and the linter will analyze them for potential issues and improvements.

Basic Syntax

[clean vocals 85bpm] Your lyrics here
[whispered] These words are whispered
[screamed] THESE WORDS ARE SCREAMED

Advanced Features

  • Use <cresc> and <dim> tags for gradual intensity changes
  • Add [with (background vocals)] for layering
  • Use [start whispered] gradually building [end screamed] for transitions

Common Issues

Unbalanced Tags

Make sure all opening tags [tag] are properly matched.

Conflicting Instructions

Avoid contradictory directions like [whispered screaming].

Abrupt Changes

Use transition instructions between dramatically different styles.

Tips for Better Results

  • Be specific with descriptors (use "falsetto" instead of "high")
  • Include tempo information (80bpm, 120bpm, etc.)
  • Reference specific vocal techniques when possible
  • Create a natural emotional arc throughout your song
  • Use the visualization to check your dynamic range
